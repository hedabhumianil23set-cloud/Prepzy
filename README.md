# Prepzy 🍳

Prepzy is an Android application designed to help users discover recipes, improve cooking experiences, and explore personalized meal suggestions through an intuitive mobile interface.

## Features

* Recipe Discovery
* User-Friendly Interface
* Personalized Experience
* Multiple Recipe Categories
* Easy Navigation
